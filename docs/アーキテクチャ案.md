## 1. 全体の形

```
┌──────────────── 画面（React + TypeScript、WebView2 の中） ────────────────┐
│ 背景レイヤ → 覆いとぼかし → UI（サイドバー／上の検索／曲一覧／下の再生バー）     │
│ 状態は「表示用の写し」だけを持つ。再生の正しい状態は Rust 側にある              │
└──────────────┬──────────────────────────────▲────────────────────────────┘
               │ 命令（invoke）                │ 通知（event）
┌──────────────▼──────────────────────────────┴────────────────────────────┐
│ commands：画面との窓口。薄く保ち、判断を持たない                               │
├───────────────────────────────────────────────────────────────────────────┤
│ playback（再生の進め方）：キュー・シャッフル・リピート・前後の曲・状態の保存     │
│   ▲ 画面・SMTC・ホットキー・タスクバー・トレイの操作は、全部ここを通る           │
│   ▼ 音を出す指示だけを audio へ                                               │
├──────────────────────┬────────────────────────────────────────────────────┤
│ audio（音声エンジン）  │ library（取り込み・タグ）／db（SQLite）／settings     │
│ 専用スレッドで動く     │ platform/windows（SMTC・サムネイルボタン・デバイス通知）│
└──────────────────────┴────────────────────────────────────────────────────┘
```

**UI と音声エンジンを密結合させない（原文「重要」）ための決まりは3つ。**

1. **画面は audio を直接呼ばない。**必ず playback を通す。SMTC・ホットキー・サムネイルボタン・トレイも同じ
2. **audio は「次の曲」を知らない。**渡された1曲を鳴らす・止める・位置を変える・出力先を変える、だけ。曲順は playback が持つ
3. **audio とのやりとりは、命令の通り道（チャネル）と通知の通り道の2本だけ。**audio の中の型を外に出さない

## 3. 画面

### 3-1. 層（原文2通目の3層）

| 層 | 中身 | 作り |
|---|---|---|
| 1 | 背景画像 | `object-fit: cover` を既定にする。画像は Tauri の asset プロトコルで読み、読める範囲はアプリのデータフォルダと、ユーザーが選んだ背景ファイルだけに絞る |
| 2 | 覆い＋ぼかし | 暗さ・ぼかし・UI の透明度は設定値。CSS 変数で渡す |
| 3 | UI | パネルは `rgba(15,15,22,0.70)`（Dark）。文字の読みやすさは「覆いの濃さ」で守る |

### 3-2. 色とテーマ

- **色・角丸・影・動きの時間は、全部 CSS 変数（`theme\tokens.css`）にする。**原文2通目の値をそのまま既定値に入れる
- Dark と Light は、変数の値を差し替えるだけの別ファイル。**テーマを足すときはファイルを1つ足すだけ**（原文「将来的に拡張できる構造」）
- **Light の「反転」の具体的な色は、原文に値が無い。**実装担当が Dark の値から反転で作り、画面で見せて作者に確かめる
- 動きは 100〜250ms。hover・パネル・ページ・背景・再生状態の切り替えにだけ使う。常に動くものは置かない

### 3-3. 幅が狭くなったとき（原文の順番をそのまま実装する）

| 幅（目安） | 減らすもの |
|---|---|
| 1100px 未満 | 1. サイドバーをアイコンだけに縮める（手動の折りたたみとは別に自動でも） |
| 900px 未満 | 2. 列を減らす：Genre → Album の順で隠す |
| 720px 未満 | 3. ジャケットを縮める（48px → 36px） |
| 600px 未満 | 4. 行の高さを縮める（64px → 48px） |

**幅の数字は原文に無い。**ここに書いたのは置き値で、実装担当が画面で当てて決める。
**レイアウトは CSS Grid と Flex だけで組む。**絶対座標は使わない（原文の禁止事項）。
ウィンドウの最小サイズは `tauri.conf.json` で 480×360 を置き値にする。

### 3-4. ショートカット

- **アプリ内**（Space・Ctrl+→ など原文の10個）：画面側の `shortcuts\` で受ける。検索欄などに文字を打っている間は効かせない
- **グローバル**（バックグラウンドでも効く）：Rust 側の `platform\windows\hotkeys.rs` で登録する。**既定では1つも登録しない**（Space などをグローバルに取ると他のアプリが壊れるため）。ユーザーが設定画面で個別に決める
- 登録に失敗したら（他のアプリが使用中）、そのキーを赤く示し、日本語で「このキーは他のアプリが使っています」と出す

## 4. 音声エンジン（`src-tauri\src\audio\`）

**「デコード」と「出力」を分ける。**ここがデバイス切り替えで作り直しにならないための要。

```
デコードのスレッド：Symphonia（＋libopus）で読む → rubato で出力先のレートへ変換 → 受け渡しの輪（リングバッファ）
出力のコールバック：cpal（WASAPI）が輪から取り出して鳴らす。鳴らしたフレーム数を数える
```

| 場面 | 動き |
|---|---|
| 再生位置 | **「実際に鳴らしたフレーム数」から出す。**デコードした位置ではない。だから切り替えても位置がずれない |
| シーク | デコーダを指定位置へ動かし、輪を空にする |
| デバイスの切り替え | 出力だけを止める → 鳴らした位置を覚える → 新しいデバイスで cpal のストリームを開く → レートが違えば変換器を作り直す → 覚えた位置へシークして再開。**曲も位置も保たれる** |
| 切断（`DeviceNotAvailable`／`StreamInvalidated`） | 既定のデバイスへ切り替え、上と同じ手順で続ける。画面に「◯◯が切断されたので、△△で再生を続けます」と出す。既定デバイスも無ければ一時停止して知らせる |
| 一覧の更新 | `platform\windows\device_watch.rs` が Windows の通知を受け、**コールバックの中では何も待たずに**通知の通り道へ流すだけ（公式の制約） |
| 通知の頻度 | 再生位置は 1 秒に 4 回ほど。状態の変化・曲の終わり・エラーはその都度 |

**音量とミュートは audio の中で掛ける**（OS の音量ミキサーは触らない）。

## 5. データベース（`src-tauri\src\db\`）

SQLite（rusqlite の `bundled`）。**WAL モード**にして、読み込み中でも書き込みで画面が止まらないようにする。

| 表 | 主な列 | 要点 |
|---|---|---|
| `library_folders` | path・サブフォルダを含むか・追加日時 | 「フォルダ追加」の記録。再走査に使う |
| `tracks` | id・**path（一意）**・大きさ・更新日時・形式・長さ・タグ10項目・アートの有無・追加日時・最終再生日時・再生回数・お気に入り・**見つからない印** | **音声ファイルはコピーしない。パスを持つだけ**（原文） |
| `tracks_fts` | title・artist・album | FTS5（trigram）。`tracks` と同期させるトリガを置く |
| `playlists` / `playlist_items` | 名前・並び順／プレイリストID・位置・曲ID | 並び替えは位置の振り直し |
| `queue_items` | 位置・曲ID | キュー |
| `playback_state` | 現在の曲・位置・音量・ミュート・シャッフル・リピート・出力デバイスID | 1行だけ |
| `settings` | キー・値（JSON） | テーマ・背景・UI・ショートカット・ホットキー・トレイの振る舞い |
| `album_art_overrides` | アルバムの鍵・画像の保存先 | 外部画像を設定したアルバム |

**検索：**曲名・アーティスト・アルバムを、打つたびに引く（原文「リアルタイム検索」）。
3文字以上は FTS5、**1〜2文字は LIKE**（trigram が3文字未満を引けないため）。画面側で 120ms ほど待ってまとめて引く。
**索引：**artist・album・genre・追加日時・最終再生日時・お気に入りに張る。

**画像は DB に入れない。**埋め込みアートの縮小版と、ユーザーが設定した外部アート・背景は、アプリのデータフォルダ（`%APPDATA%\<識別子>\`）の下に保存する。
**音声ファイルはコピーしない。画像だけは複製する**（設定の書き出しで持ち運べるようにするため）。

## 6. 取り込みとタグ（`src-tauri\src\library\`）

- **取り込み**：ファイル選択・複数選択・フォルダ追加（サブフォルダまで）・ドラッグ＆ドロップの4経路を、全部同じ `import.rs` に流す。走査は別スレッドで行い、進み具合を画面へ通知する
- **対応形式の判定**：拡張子で候補を絞り、中身は Symphonia で確かめる。開けないものは「非対応形式」として数え、最後にまとめて知らせる
- **タグの書き込み**：`技術調査.md` 7章の5段階（同じフォルダに一時ファイル → 書く → 読み直しと復号で確かめる → `ReplaceFileW` → 失敗なら一時ファイルを消す）
- **再生中の曲のタグを書くとき**：差し替えの前に、その曲のデコーダを閉じて位置を覚え、差し替え後に開き直す

## 7. Windows 連携（`src-tauri\src\platform\windows\`）

| 部品 | 作り |
|---|---|
| SMTC | `ISystemMediaTransportControlsInterop::GetForWindow` で取り、再生・一時停止・次・前・位置を受ける。曲名・アーティスト・アート・再生位置を送る |
| サムネイルボタン | 前・再生/一時停止・次の3つを起動時に一度だけ定義する。再生と一時停止は絵柄の差し替えで切り替える |
| トレイ | Tauri の `tray-icon`。メニューは「表示」「再生/一時停止」「次」「前」「終了」 |
| ×ボタン | 設定が「トレイへ」なら閉じる要求を止めて隠す。「終了」なら状態を保存して終わる |
| 二重起動 | `tauri-plugin-single-instance` で、2つ目を起動したら1つ目を前に出す（メディアキーの取り合いを防ぐ） |

## 8. 状態の保存と、設定の書き出し

- **保存の時機**：終了するとき・曲が変わったとき・10秒ごと（位置）。**落ちても最後の数秒しか失わない**
- **復元**：起動時に `playback_state`・`queue_items`・ウィンドウの位置と大きさを戻す。**自動では再生しない**（一時停止で位置だけ戻す）
- **書き出し**：テーマ・背景・UI 設定・ショートカット・プレイリスト・お気に入り・ライブラリ設定を、1つの zip（中身は JSON と背景画像）にまとめる。曲は**パス**で持つので、別の PC で読み込むと見つからない曲が出る。読み込みのときに件数を知らせる

## 10. エラーの扱い

`error.rs` の `AppError` に、原文の8種をそのまま種別として置く。
ファイル不存在・アクセス拒否・非対応形式・タグ読み込み失敗・タグ書き込み失敗・再生デバイス切断・音声再生エラー・データベースエラー。
**画面は種別コードから `src\messages\ja.ts` の文を引く。**Rust 側で日本語の文を作らない（言い回しを1か所で直せるように）。

## 11. v2 に回す候補（実装中に見つけたら、ここへ書き足す）

**今の時点で、原文どおりにいかない恐れがあるものだけを書く。v1 では削らない。**

| 項目 | 恐れ | v1 での扱い |
|---|---|---|
| HE-AAC の m4a | Symphonia が未対応で鳴らない | v1 は AAC-LC と ALAC。HE-AAC の曲は「非対応形式」として知らせる。v2 で手段を検討する（`技術調査.md` 2-1）。**v3.1.2：Symphonia が読めない AAC だけ Windows の Media Foundation で鳴らす（`platform\windows\mf_audio.rs`。`audio\decoder.rs` が切り替える。外から見た形は同じ）** |
| Light テーマの具体色 | 原文に値が無い | 反転で作って作者に見せる。**v3.1.2：コントラスト比を計算して作り直した（`docs\テーマの色の根拠.md`）** |
