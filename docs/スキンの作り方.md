# スキンの作り方（PL Player 3.2.0）

PL Player の見た目を変える「スキン」を作る人向けの手引きです。決まりの全文は `docs\着せ替え_仕様.md`（この手引きと食い違ったら、そちらが正）。

## 1. 変えられるもの・変えられないもの

| 変えられる | 変えられない（3.2.0） |
|---|---|
| 色（Dark・Light 別に）・文字の種類・文字の大きさ（±2px まで）・角丸・影・動きの速さ | 画面の作り・寸法（サイドバーの幅・行の高さ・再生バーの高さなど） |
| ボタンのアイコン 34 個（状態のあるものは状態ごと） | 背景画像（使う人の設定のまま） |
| 起動中のウィンドウ・タスクバー・タスクトレイのアイコン | exe・スタートメニュー・ショートカットのアイコン |
| 立ち絵（再生中・停止中の2枚。画面の右側） | 自作の CSS・フォントのファイル・音・SVG |

使う人が選べるスキンは1つです。部品は全部そろえなくてかまいません（色だけ・立ち絵だけのスキンも作れます）。持っていない部品は、いつもの見た目のままです。

## 2. 要る道具

- 画像を作る道具（PNG・WebP・GIF を書き出せるもの。動く画像なら APNG か動く WebP か GIF）
- テキストエディタ（`skin.json` を UTF-8 で保存できるもの）
- zip を作る道具（Windows のエクスプローラーの「送る → 圧縮（zip 形式）フォルダー」で足ります。パスワードは付けない。作り方は 10 章）

## 3. いちばん小さいスキン

フォルダを1つ作り、`skin.json` を置きます。

```
my-skin\
└─ skin.json
```

色だけのスキン：

```json
{
  "format": "pl-player-skin",
  "schemaVersion": 1,
  "id": "my-colors",
  "name": "My Colors",
  "version": "1.0.0",
  "author": "your name",
  "parts": {
    "appearance": {
      "themes": {
        "dark": {
          "tokens": {
            "--c-bg": "#111319",
            "--c-panel-rgb": "28, 30, 38",
            "--c-accent": "#d08a55",
            "--c-accent-contrast": "#17130f"
          },
          "shadow": "soft"
        }
      }
    }
  }
}
```

**`id` は英小文字・数字・`-` だけ（48 文字まで）。**同じ id のスキンは、入っている方を消さないと取り込めません。版を上げるときも、使う人には古いほうを消してもらってから取り込み直してもらいます。

全部の部品を使う例：

```json
{
  "format": "pl-player-skin",
  "schemaVersion": 1,
  "id": "my-skin",
  "name": "My Skin",
  "version": "1.0.0",
  "author": "your name",
  "description": "説明（300 文字まで）",
  "minAppVersion": "3.2.0",
  "preview": "preview.png",
  "parts": {
    "appearance": {
      "themes": { "dark": { "tokens": { "--c-accent": "#d08a55" } }, "light": { "tokens": { "--c-accent": "#87502b" } } },
      "fontFamily": ["Yu Gothic UI"],
      "tokens": { "--fs-body": 15, "--radius": 6 }
    },
    "icons": {
      "IconPlay": "icons/play.png",
      "IconPause": "icons/pause.png",
      "IconStar": { "outline": "icons/star-outline.png", "filled": "icons/star-filled.png" }
    },
    "application": { "window": "app/window.png", "tray": "app/tray.png" },
    "character": {
      "states": { "playing": "character/playing.webp", "stopped": "character/stopped.png" },
      "placement": { "mode": "right-rail", "widthPx": 180, "maxHeightPx": 420, "minWindowWidthPx": 920 }
    }
  },
  "extensions": {}
}
```

## 4. 配色

- 色は `parts.appearance.themes.dark.tokens` と `…light.tokens` に、変数の名前と値で書きます。使える名前と値の形は仕様の4章（`#rrggbb`・`#rgb`・`rgb(…)`・`rgba(…)`。`--c-panel-rgb` と `--c-overlay-rgb` だけは `r, g, b`）
- 変えられる色は 15 個です：`--c-bg` `--c-panel-rgb` `--c-overlay-rgb` `--c-primary` `--c-secondary` `--c-accent` `--c-accent-contrast` `--c-hover` `--c-selected` `--c-border` `--c-outline` `--c-input` `--c-danger` `--c-ok` `--c-favorite`
- **v3.7.0 で2つ足しました**：`--c-outline`（ボタン・入力欄・行のボタンの輪郭。`--c-border` は飾りの区切り線）と `--c-favorite`（お気に入りにした曲の星。ほかのボタンのオンの色は `--c-accent`）。3.6.0 までの版はこの2つを知らない名前として飛ばします（取り込みは断らず、ほかの色は当たります）。この2つが要るスキンは `minAppVersion` を `"3.7.0"` にしてください
- **v3.7.0 で Dark のいつもの色が変わりました**：`--c-accent` が明るい紫 `#b3aaff` に、その上の文字 `--c-accent-contrast` が白から黒 `#08080c` に、操作部の輪郭が `--c-border` から `--c-outline` に。3.6.0 までのスキンで `--c-accent` だけを暗い色に変えていると、ボタンの上の文字が黒になって読みにくくなります。**`--c-accent` を変えるときは `--c-accent-contrast` も一緒に書いてください。**`--c-border` で操作部の線を調整していたスキンは、`--c-outline` も書いてください
- 片方のテーマしか書かなければ、もう片方はいつもの色のままです
- **文字が読めるかを確かめてください。**取り込みの確認画面で、本文 4.5:1・線とお気に入りの星 3:1 に届かない組み合わせを警告します（背景画像なし・白・黒の上で計算）。警告があっても取り込めますが、使う人が読みにくくなります
- 影は `"shadow": "none" | "soft" | "standard"` から選びます
- 文字の大きさは、いつもの大きさから ±2px までです（行の高さは変わらないので、大きくしすぎると文字がはみ出すため）

## 5. アイコン

- 名前は次の 34 個：`IconMusic` `IconUser` `IconDisc` `IconTag` `IconClockPlus` `IconHistory` `IconStar` `IconList` `IconQueue` `IconSettings` `IconSearch` `IconPlus` `IconFolderPlus` `IconFilePlus` `IconPlay` `IconPause` `IconNext` `IconPrev` `IconShuffle` `IconRepeat` `IconVolume` `IconX` `IconTrash` `IconEdit` `IconImage` `IconSidebar` `IconRefresh` `IconFolder` `IconChevron` `IconBars` `IconLyrics` `IconBack` `IconLyricsRow` `IconRanking`
- `IconRanking`（サイドバーの「年間まとめ」）は v3.6.0 からです。3.5.0 までのアプリは知らない名前として取り込みを断るので、使うときは `minAppVersion` を `3.6.0` にしてください
- 状態があるもの：`IconStar`（`outline`・`filled`）・`IconVolume`（`muted`・`zero`・`low`・`high`）・`IconRepeat`（`off`・`all`・`one`）・`IconShuffle`（`off`・`on`）。どれも `default` も書けます。状態の画像が無いときは `default`、それも無ければいつもの線のアイコンです
- テーマで変えたいときは `{"dark": "icons/play-dark.png", "light": "icons/play-light.png"}` と書きます（画像の色はアプリが変えないので、Light では暗い色の画像が要ります）
- 大きさは 96×96px をすすめます（画面では 16〜20px で出し（サイドバーの項目のアイコンは、使う人の設定で 14〜32px。v3.4.0）、高い解像度の画面でも粗くならないように）。上下左右に 10〜15% ほど透明の余白を取り、線は細くしすぎないでください
- 動くアイコンも使えますが、ボタンが動き続けると気が散るので、止まったものをすすめます

## 6. アプリ・トレイのアイコン

- `app/window.png`（ウィンドウとタスクバー）は 256×256px、`app/tray.png`（タスクトレイ）は 32×32 か 64×64px の透明の PNG をすすめます。トレイが無ければウィンドウの画像を使います
- **静止画だけ**です（動く画像は取り込めません）
- 変わるのは起動中のウィンドウ・タスクバー・トレイだけです。exe・スタートメニュー・ショートカットのアイコンは変わりません

## 7. 立ち絵

- 再生中（`playing`）と停止中（`stopped`）の2枚が要ります。一時停止と曲を選んでいないときも停止中の絵です
- 置き方は `"mode": "right-rail"` だけです。画面の右側に `widthPx` の幅を取り（曲一覧はその左まで）、絵を下にそろえて出します
- `widthPx` 96〜280・`maxHeightPx` 160〜520・`minWindowWidthPx` 760〜1200。ウィンドウがそれより狭いときと歌詞画面では隠れます。使う人が大きさを 75〜125% に変えられます
- すすめる大きさは 720×1280px の縦長・透明の背景。画面の下の端と左右の端で切れても困らない向きにしてください
- 立ち絵はクリックを受けません（下の画面を押せます）

## 8. 動く画像

- 使える形：GIF・APNG（拡張子は `.png`）・動く WebP（`.webp`）
- 上限：120 コマ・90 秒・縦横 4096px。全部のコマを合わせた画素は 1億 2,800 万まで（720×1280 なら 120 コマ入ります）
- 使う人が Windows の「アニメーション効果」を切っているときは、最初の1コマを止まった絵として出します。**最初の1コマだけを見ても分かる絵にしてください**
- 1コマを 10ms 以下にしたものは、100ms として数えます

## 9. 文字の種類（フォント）

`"fontFamily": ["名前", …]` に、使う人の PC に入っているフォントの名前だけを書けます（8つまで。前から順に探し、無ければいつもの文字）。フォントのファイルは zip に入れられません（再配布の許可の確かめと、アプリが読める範囲を広げることを避けるため）。

## 10. zip の作り方（取り込めない zip）

**作り方（Windows）**：スキンのフォルダ（`skin.json` が入っているフォルダ）を右クリック →「送る」→「圧縮（zip 形式）フォルダー」。フォルダの名前は日本語でもかまいません（取り込むときに外して読むので、名前は使いません）。Windows 11 では右クリック →「ZIP ファイルに圧縮する」でも同じです。

**作り方（PowerShell）**：スキンのフォルダの中で、次のどちらかを打ちます。Windows に最初から入っている PowerShell（5.1）でも、PowerShell 7 でも同じです（5.1 は zip の中の区切りを `\` で書きますが、取り込むときに `/` に読み替えます）。

```powershell
# 中身だけを zip にする（zip のいちばん上に skin.json が来る）
Compress-Archive -Path .\* -DestinationPath ..\my-skin.zip
# フォルダごと zip にする（スキンのフォルダの1つ上で打つ。<フォルダ> はスキンのフォルダの名前）
Compress-Archive -Path .\<フォルダ> -DestinationPath .\my-skin.zip
```

**作り方（macOS）**：スキンのフォルダを右クリック →「圧縮」。macOS が足す `__MACOSX` と `.DS_Store` は、取り込むときに飛ばします（確認の画面に「無視したファイル」として数だけ出ます）。

- `skin.json` は、zip のいちばん上か、zip の中のただ1つのフォルダの中に置きます。フォルダの中にさらにフォルダを作り、その中に `skin.json` を置いた形（2段）は取り込めません
- 入れてよいのは `skin.json`・`preview.png`（か `.webp` `.gif`）と、`icons\`・`app\`・`character\` の中の画像だけです。フォルダは3段まで（`icons\IconStar\filled.png`）
- **フォルダの中のファイル・フォルダの名前は英数字と `.` `_` `-` だけ**（いちばん外のフォルダを除く）。空白・日本語は使えません（zip の中の名前の文字コードは作る道具によって違い、読み違えないため）。大文字小文字だけ違う名前を2つ置けません
- `skin.json` が使っていない画像・説明の txt などが入っていると取り込めません（`Thumbs.db`・`desktop.ini`・`.DS_Store`・`__MACOSX` は飛ばすので、入っていてもかまいません）
- 実行ファイル・スクリプト（`.exe` `.js` など）・SVG・CSS・フォントが入っていると取り込めません
- 大きさ：zip 25MB・展開後 80MB・ファイル 64 個・画像1つ 15MB まで
- パスワードを付けた zip は取り込めません

## 11. 取り込み・確かめ・うまくいかないとき

1. 設定の「着せ替え」→「＋ zip を取り込む…」で zip を選ぶ
2. 確認の画面で、名前・部品・ファイルの数・大きさ・警告を見る。「このスキンを取り込む」
3. 一覧のスキンの「適用」で当てる

断られたときは、出た文（何が引っかかったか）と、その下の小さな字（どのファイルか）を見て直してください。
見た目が読めなくなったら、タスクトレイのアイコンを右クリック →「既定の見た目に戻す」で戻せます。起動の指定 `--safe-mode` を付けて起動しても、既定の見た目になります。

入っているスキンは「書き出す…」で zip にできます（`skin.json` と、それが使う画像だけ）。

## 12. 権利

- 使う絵・写真・フォントの名前などは、配ってよいものだけを使ってください。他人の作ったキャラクターの絵を使うときは、その権利を持つ人の決まりに従ってください
- `author` に作者の名前、`description` に素材の出どころを書いておくと、使う人が確かめられます
