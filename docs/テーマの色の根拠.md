# テーマの色の根拠（Light・v3.1.2）

作成：2026-11-12。v3.1.2 で Light テーマの色（`src\theme\light.css`）を作り直したときの計算の記録。
**Dark（`src\theme\dark.css`）は変えていない。**変数の名前（`--c-*`）も変えていない。

## 1. 何を直したか

3.1.1 までの Light は、Dark の値を反転（255 − 値）して作った仮の色だった。
暗い背景画像の上では、説明の文字・アクセントの文字・エラーと成功の文字・線が、文字と背景の濃さの差の基準に届いていなかった（下の 4章の「3.1.1」の列）。

基準は WCAG 2.x のコントラスト比：

| 何 | 基準 |
|---|---|
| 本文（12〜17px の文字。曲名・アーティスト・説明・ボタンの文字） | 4.5:1 以上 |
| 大きい文字・線（入力欄とボタンの枠・区切り・フォーカスの枠・シークバー） | 3:1 以上 |

本文の基準を、大きい文字にもそのまま当てた（画面の文字はどれも本文の基準を満たす）。

## 2. 計算のしかた

**画面と同じ重ね方で、文字の下に実際に来る色を作ってから比べる。**

```
背景画像（白 #ffffff ／ 黒 #000000 ／ 画像なしなら --c-bg）
  → 覆い  rgba(--c-overlay-rgb, 背景の暗さ)
  → パネル rgba(--c-panel-rgb, UI の不透明度)
  → 行の色（選んだ行 --c-selected・指を乗せた行 --c-hover・入力欄 --c-input）
  → 文字・線
```

- 半透明の色は、ブラウザと同じく sRGB の値のまま混ぜた（α合成）。比は WCAG 2.x の相対輝度の式
- 背景画像は、いちばん明るい白といちばん暗い黒の両方で計算した。どんな写真もこの2つの間に入る
- 背景画像なしのときは、覆いの暗さは 0（`src\layout\BackgroundLayer.tsx`）で、下は `--c-bg`
- 設定は既定の値：背景の暗さ 45%・UI の不透明度 70%（`src\stores\settings.ts`）。**この文書の比はどれも既定の設定での値。**不透明度を下げる・暗さを動かすと基準を下回ることがある（例：黒い背景画像・暗さ 0%・不透明度 30% では、パネルが `#4c4c4b` 前後になり、本文の比が 2.43 まで下がる）
- メニュー・知らせ・流れる歌詞の列は、パネルの色を 0.92〜0.98 の不透明度で重ねている（`src\theme\base.css`）。いちばん薄い 0.92 で計算した
- ぼかし（`--bg-blur`・`backdrop-filter`）は一様な色を変えないので、計算に入れていない

計算は `scripts\theme-contrast.mts`、基準を満たすかの確かめは `scripts\theme-contrast.test.mts`（どちらも依存は要らない）：

```
node scripts/theme-contrast.mts             # 5章・6章の表を出す
node --test scripts/theme-contrast.test.mts # 基準・変数の名前・Dark が変わっていないことを確かめる
```

## 6. 設定を変えたとき

背景の暗さ（覆い）と UI の不透明度（パネル）は設定画面で変えられる。暗い背景画像（黒）で、5章の組み合わせが全部基準を満たす UI の不透明度の最小値：

| 背景の暗さ | 基準を満たす UI の不透明度（最小） |
|---|---|
| 0% | 82% |
| 15% | 79% |
| 30% | 74% |
| 45% | 67% |
| 60% | 55% |
| 75% | 30% |
| 95% | 30% |

- 既定（暗さ 45%・不透明度 70%）は満たす（最小 67%）
- 暗さを 0〜30% に下げて暗い背景画像を使うときは、UI の不透明度を 74〜82% 以上にする必要がある。設定画面の「文字が読みにくいときは、暗さか不透明度を上げてください」の案内のとおり
- 明るい背景画像（白）と背景画像なしは、どの設定でも満たす（覆いとパネルが白に近いため）

次は、わざと薄くしている表示。Dark と共通の `src\theme\base.css` の `opacity` で薄くしているので、今回は変えていない（Dark を変えないため）。

| 表示 | 薄さ | 理由 |
|---|---|---|
| 押せないボタン（`.btn:disabled`） | 0.45 | 押せないことを示す表示。WCAG も押せない部品は基準の対象外としている |

## 8. 目で確かめてほしいこと

- 計算は白と黒の一様な背景で行った。細かい模様の写真では、ぼかしの強さによって読みやすさが変わる
- 線（`--c-border`）は 3:1 に届くよう濃くしたので、区切り線・パネルの縁が 3.1.1 よりはっきり見える。濃すぎると感じたら、入力欄の枠だけを別の変数にする案がある（変数を足すので Dark にも足すことになる）
- アクセントは Dark（`#7c6cff`）より濃い紫（`#4232c2`）になった
