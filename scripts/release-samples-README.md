# 見本（PL Player {{VERSION}}）

自分の立ち絵やスキンを作るときの見本と、アイコンを1つずつ入れるときの画像です。絵はどれも、図形だけで描いたものです。

| ファイル・フォルダ | 中身 |
|---|---|
| `くじら_再生中.png` | 立ち絵の見本「くじら」の、曲を流している間の絵（450×950px・透明の背景） |
| `くじら_停止中.png` | 同じく、止めている間の絵 |
| `ペンギン_再生中.png` | 立ち絵の見本「ペンギン」の、曲を流している間の絵（450×950px・透明の背景） |
| `ペンギン_停止中.png` | 同じく、止めている間の絵 |
| `くもくじら.zip` | スキンの見本「くもくじら（見本）」。色（Dark・Light）・ボタンのアイコン全部・ウィンドウとタスクトレイのアイコン・立ち絵（くじら） |
| `ペンギン.zip` | スキンの見本「ペンギン（見本）」。中身の種類は「くもくじら」と同じ（立ち絵はペンギン） |
| `アイコン\くじら` | 「くもくじら」のアイコンを、1つずつ入れる用に並べたもの（ボタンのアイコンと、ウィンドウ・タスクトレイのアイコン） |
| `アイコン\ペンギン` | 同じく「ペンギン」のアイコン |

## スキンを当てる

`くもくじら.zip` と `ペンギン.zip` は、そのまま取り込めるスキンです。

1. 設定 → 着せ替え →「＋ zip を取り込む…」で zip を選ぶ
2. 確認の画面で「このスキンを取り込む」を押す
3. 一覧のスキンの「適用」で当てる（取り込んだだけでは当たりません）

当てられるスキンは1つです。もう片方に替えるときは、一覧でそちらの「適用」を押してください。元の見た目に戻すときは「既定の見た目に戻す」を押します。

zip を展開すると、中の `skin.json` と画像が見られます。書き方は、公開ページの `docs/スキンの作り方.md` にあります。

## アイコンを1つずつ入れる

`アイコン\くじら` と `アイコン\ペンギン` のフォルダには、スキンの zip の中と同じアイコンが入っています。ファイルの名前は、設定の「アイコン」の欄の枠の名前と同じです（状態のある枠は「シャッフル_切.png」「リピート_1曲.png」のように、名前と状態を `_` でつないでいます）。

1. 設定 → 着せ替え →「アイコン」の欄を開く
2. このフォルダから画像を1つ、同じ名前の枠へドラッグ＆ドロップする（枠を押して画像を選んでもかまいません）
3. そのアイコンがすぐ替わる。戻すときは、枠の「戻す」を押す

くじらとペンギンのアイコンを混ぜてもかまいません。自分で描いた画像（PNG・WebP・GIF）も同じように入れられます。

手で入れたアイコンは、当てているスキンのアイコンより優先します。**スキンを替えても、手で入れたアイコンはそのまま残ります。**全部外すときは、欄の下の「手で入れたアイコンを全部戻す」か「既定の見た目に戻す」を押してください。

## 立ち絵を作る

「くじら」は、アプリに最初から入っています（設定 → 着せ替え →「立ち絵」の欄）。「ペンギン」は、`ペンギン.zip` を取り込むと「立ち絵」の欄に出ます（この2枚を「＋ 立ち絵を追加…」で入れてもかまいません）。

自分の立ち絵にするときは、この絵を自分の絵に差し替えて、設定 → 着せ替え →「＋ 立ち絵を追加…」で入れれば足ります。再生中の絵を選び、停止中の絵を選び（無くてもかまいません。止めている間も再生中の絵が出ます）、名前を入れて「追加」。追加しただけでは出ないので、一覧のカードを押して切り替えてください。

| 項目 | 決まり |
|---|---|
| 形式 | PNG・WebP・GIF。動く画像（APNG・動く WebP・動く GIF）も使えます |
| 背景 | 透明にすると、アプリの画面の上に絵だけが出ます |
| 向き | 縦長がおすすめです。絵は高さに合わせて出し、幅は縦横比のまま決まります。右の立ち絵の欄（窓の幅で 140〜480px に変わる）より広い絵は、左右が同じだけ切れます。横長の絵は左右が切れやすいので、真ん中に大事なものを置いてください |
| 大きさ | 1枚 15MB まで・縦横 4096px まで。すすめる大きさは 720×1280px くらいの縦長です（くじらは 450×950px）。窓が狭いと右の欄は細くなるので、顔など大事なものは絵の真ん中の半分くらいの幅に収めると切れにくくなります |
| 動く画像 | 120 コマ・90 秒まで |
| 数 | 30 体まで |

絵は画面の下の端にそろえて出ます。下の端が切れても困らない絵にしてください。
