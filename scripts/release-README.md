# PL Player {{VERSION}}

3.0.0 以降と同じアプリです（名前・データの場所・インストール先は変わりません）。前の版のライブラリ・設定・歌詞をそのまま使います。ふだんの使い方は変わりません。

## 3.10.0 で変えたこと

アプリの色を、1つずつ手で選べるようにした版です。前の版から上げても、手で選んだ色は無いので、見た目は変わりません。

- **色を選ぶ**：設定の「着せ替え」に「色」の欄を足しました。背景・文字・アクセント・区切り線など 15 個の色が並び、見本の四角を押すと色を選べます。選んだ色はすぐ画面に出ます（保存のボタンはありません）
- **濃さ**：半透明の5色（指を乗せたとき・選んだ行・区切り線・操作部の輪郭・入力欄）は、色の隣のつまみで濃さも選べます。板の色（パネル）と重ねる面の色の濃さは、今までどおり「表示」の「UI の不透明度」と「背景の暗さ」で決まります
- **スキンとの関係**：手で選んだ色は、当てているスキンの色より優先します。スキンを替えても、手で選んだ色は残ります
- **Dark と Light**：手で選んだ色は1組だけで、どちらのテーマにも同じ色が当たります。テーマを切り替えて読みにくくなったときは、欄の上に知らせが出ます（使うことはできます）
- **戻す**：色ごとの「戻す」で、その色だけスキンの色か既定の色に戻ります。欄の下の「手で選んだ色を全部戻す」で全部戻せます。「既定の見た目に戻す」（設定・タスクトレイ）でも、手で選んだ色は全部戻ります（立ち絵は残ります）
- **設定のバックアップ（zip）**：手で選んだ色も入るようになりました。読み込むと置き換わります。前の版で書き出した zip を読み込んだときは、今の色を変えません
- **直したこと**：スキンの取り込みの確認画面で、色の読みやすさの警告が出ていなかったのを直しました（前の版では、読みにくい色のスキンでも「読みやすさの基準を満たしています」と出ていました）

## 3.9.1 で変えたこと

見本の立ち絵「くじら」を、アプリに最初から入れた版です。

- **新しく入れた人**：初めて起動したときから、右にくじらが出ます。ほかの立ち絵にするときは、設定の「着せ替え」の「立ち絵」の欄で選び直してください（「出さない」も選べます）
- **前の版から上げた人**：「立ち絵」の欄の一覧に、くじらが1体増えるだけです。今選んでいる立ち絵と見た目は変わりません。30 体いっぱいまで追加していたときは増えません
- **くじらを消したとき**：くじらは、自分で追加した立ち絵と同じように変更・削除できます。消したくじらは、次に起動しても、版を上げても戻りません
- **見本のフォルダ**：この zip に「見本」フォルダを足しました。くじらの絵2枚と、スキンの見本「くもくじら」の zip と、使い方が入っています。自分の立ち絵やスキンを作るときの下敷きにしてください

## 3.9.0 で変えたこと

立ち絵を、スキンとは別に選べるようにした版です。前の版で出していた立ち絵は、上げたあともそのまま選ばれています（「立ち絵を出す」を切っていた人は「出さない」になります）。ただし出し方は下の「立ち絵の出し方」のとおり変わるので、前より大きく出て、左右が少し切れることがあります。

- **立ち絵を追加する**：設定の「着せ替え」の「立ち絵」の欄の「＋ 立ち絵を追加…」で、画像を選ぶだけで立ち絵を足せます（zip も設定ファイルも要りません）。PNG・WebP・GIF（動く画像も）。曲を流している間の絵と、止めている間の絵を別々に入れられます（止めている間の絵は無くてもかまいません）。名前を入れなければ、ファイル名が名前になります。30 体まで。画像は PC の中のアプリのフォルダに写すだけで、外へは送りません
- **立ち絵を選ぶ**：一覧のカードを押すと、その立ち絵に切り替わります。「スキンの立ち絵」「出さない」・取り込んだスキンの立ち絵・追加した立ち絵から選べます。スキンを替えても、選んだ立ち絵はそのままです
- **立ち絵を変える・消す**：追加した立ち絵のカードの「変更」で、流している間の絵・止めている間の絵を1枚ずつ差し替えたり、名前を変えたりできます。「削除」で消せます
- **立ち絵を出さない**：設定の「既定の見た目に戻す」の隣と、タスクトレイのメニューに「立ち絵を出さない」を足しました。「既定の見た目に戻す」ではスキンだけが戻り、立ち絵は残ります
- **立ち絵の出し方**：右の立ち絵の欄の幅は、窓の大きさに合わせて変わります（どの立ち絵でも同じ幅）。絵は高さに合わせて大きく出し、はみ出した左右は切れます。大きさは 75〜200% まで選べます。窓が足りないときは、まず欄を縮め、それでも足りないときに隠します。「詳細」の表示でも出ます
- **曲一覧の列**：立ち絵を出しているときは、立ち絵を除いた広さで、アルバム・ジャンルの列を出すか決めます

## 3.8.1 で変えたこと

不具合の直しの版です。

- **グローバルホットキー**：設定を保存した瞬間とホットキーを押した瞬間が重なると、アプリが固まって戻らないことがあったのを直しました
- **グローバルホットキーの消し方**：割り当てを消すキーを Esc に変えました。設定の「キー操作」で枠を押し、「キーを押してください…」と出ている間に Esc を押します（前は Delete・Backspace）。割り当てずにやめるときは、枠の外を押します

## 3.8.0 で変えたこと

いくつかの再生デバイスへ、同じ曲を同時に流せるようにした版です。前の版から上げると、今選んでいるデバイスがそのまま出力先1に入り、今までどおりに鳴ります。

- **同時に鳴らす**：3つまでの再生デバイス（ヘッドホン・スピーカー・仮想オーディオケーブルなど）へ、同じ曲を同時に流せます。再生バーの出力ボタン（音量の左）を押すと、出力先ごとのオン／オフ・音量・細いメーターが出ます
- **詳細の表示**：上の帯の右端の「通常／コンパクト／詳細」の「詳細」で、曲一覧の横に「出力」のミキサーが出ます。出力先の追加・外す・左右のメーター・遅らせ量（0〜1000 ミリ秒。デバイスどうしを合わせるもの）を扱えます
- **遅れを測る**：出力のプルダウンか詳細のミキサーの「遅れを測る…」で、出力先ごとに短いクリック音を鳴らして届くまでの遅れを測り、揃える遅らせ量を入れられます。曲を止めているときだけ使えます。クリック音が配信・録画に乗るので、止めてから測ってください。出る値は「だいたいの値」です（下の「既知の制限」）
- **デバイスが抜けたとき**：その出力先だけ「切断中」になり、つなぎ直すと今の位置から戻ります。前の版のように既定のデバイスへは移りません。全部の出力先が使えなくなったら一時停止します
- **再生バー**：窓の幅に合わせて、3列と1段（高さ 76px）の形を自動で切り替えます。入りきらないボタンは「···」の中へ移ります
- **曲一覧のコンパクト表示**：上の帯の「通常／コンパクト」でも切り替えられます。設定は「使わない／いつも」と「窓が狭いときは自動でコンパクトにする」のチェックになりました（前の版の設定は同じ見た目になるように読み替えます）
- **ウィンドウ**：いちばん小さい大きさを 480×360px から 480×480px にしました
- **歌詞**：歌詞の画面を開いている間も、再生バーの下の流れる歌詞の列を出すようにしました
- **設定のバックアップ（zip）**：出力先の設定も入るようになりました。**再生デバイスの名前が入るので、人に渡すときは気をつけてください。**読み込むと一時停止して、出力先は全部オフで入ります
- **直したこと**：起動した直後に「応答なし」のまま戻らないことがあったのを直しました

## 中身

| ファイル | 使い方 |
|---|---|
| `PL Player 3_{{VERSION}}_x64-setup.exe` | インストーラー（今のユーザーにだけ入れる。管理者権限は要らない） |
| `PL Player 3（インストールせずに使う）.exe` | インストールせずにそのまま起動できる版。中身はインストーラーと同じ |
| `見本\` | 立ち絵の見本（くじらの絵2枚）・スキンの見本（`くもくじら.zip`）・使い方（`README.md`）。アプリを使うだけなら要りません |

どちらを使っても、ライブラリ・設定は同じ場所（`%APPDATA%\jp.local.plplayer3\`）に置かれます。スタートメニューに出したいときはインストーラーを、置いた場所から起動するだけでよいときはインストールせずに使う版を選んでください。

## 「Windows によって PC が保護されました」と出たら

このアプリには、配った人を証明する署名（コード署名）を付けていません。そのため、初めて起動するときに Windows の青い画面（SmartScreen）が出ることがあります。

1. 画面の「詳細情報」を押す
2. 下に出る「実行」を押す

ダウンロードしたファイルが途中で壊れたり差し替えられたりしていないかは、公開ページの SHA256 の一覧（`PL-Player-{{VERSION}}.sha256.txt`）と照らして確かめられます。一覧に載っているのは公開ページに置いた名前（`PL-Player-{{VERSION}}.zip`・`PL-Player-{{VERSION}}-x64-setup.exe`・`PL-Player-{{VERSION}}-x64-portable.exe`）です。この zip から出した exe 2つは、名前は違いますが、それぞれ `-x64-setup.exe`・`-x64-portable.exe` と同じ中身なので、PowerShell の `Get-FileHash <ファイル>` の値が一覧のその行と同じになります（`Get-FileHash` は英字を大文字で、一覧は小文字で書いていますが、大文字小文字は問いません。英字の大小を無視して並びだけを見てください）。照らし方の全文は、公開ページの `README.md` の「入手」にあります。

## 気をつけること

- 「ごみ箱へ移す」は、USB メモリなどごみ箱の無い場所にある曲と、ごみ箱を使わない設定にしたドライブの曲は移しません（移すと完全に消えてしまうため）。ほかのアプリが使っている曲も移せません。移せなかった曲は、ファイルもライブラリもそのままです
- 「ごみ箱へ移す」で、ファイルはごみ箱へ移せたのにライブラリから外せなかった曲があると、そのことを知らせます。一覧に残るので、右クリックの「ライブラリから外す…」で外してください
- 「ごみ箱へ移す」で移した曲をごみ箱から戻しても、ライブラリには自動では戻りません。取り込み直してください（ライブラリに足したフォルダの中の曲なら、設定の「ライブラリ」の「再走査」でも入ります）。プレイリストとお気に入りの印は戻りません
- 設定のバックアップ（zip）を読み込むと、「ごみ箱」の列はオフに戻ります（右クリックのメニューの「ごみ箱へ移す…」はそのまま使えます）
- スキンで変わるのは、起動中のウィンドウ・タスクバー・タスクトレイのアイコンです。exe・スタートメニュー・デスクトップのショートカットのアイコンは変わりません
- 設定のバックアップ（zip）には、スキンそのものは入りません。別の PC で同じ見た目にするときは、設定の「着せ替え」でスキンを「書き出す…」し、その zip を取り込んでください
- 手で選んだ色で画面が読めなくなったときは、タスクトレイのアイコンを右クリックして「既定の見た目に戻す」を押してください（手で選んだ色も全部戻ります）
- 背景の暗さを低く（0〜30%）して暗い背景画像を使うときは、Light テーマの文字が読みにくくなることがあります。設定画面で「UI の不透明度」を上げてください
- HE-AAC でも、ファイルの頭に HE-AAC の印が無いもの（`.aac` のファイルなど）は、今までどおり高い音が欠けて聞こえることがあります
- Media Feature Pack を入れていない N エディションの Windows では、HE-AAC の m4a は今までどおり「非対応形式」になります（アプリは起動します）

## 既知の制限

「詳細」の表示では、窓の幅によって、立ち絵が出ない所が少しあります（サイドバーが開いた直後の窓の幅 1100〜1167px など。その幅では曲一覧の側が急に狭くなるため）。窓を少し広げるか狭めると出ます。

追加した立ち絵の画像は、設定のバックアップ（zip）には入りません（どの立ち絵を選んでいるかだけが入り、その立ち絵が無い PC で読み込むと「スキンの立ち絵」に戻ります）。別の PC で同じにするときは、その PC でも立ち絵を追加してください。最初から入っているくじらも同じです（PC ごとに別の立ち絵として入るので、くじらを選んでいた設定を別の PC で読み込むと「スキンの立ち絵」に戻ります。その PC のくじらを選び直してください）。

「遅れを測る」の値は、だいたいの値です。測れるのは Windows がデバイスへ音を渡すところまでで、機器の中の遅れ（USB の先・HDMI の先・Bluetooth）は入りません。仮想オーディオケーブルの遅れは、開くたびに変わり、開いてしばらく（数秒〜10秒ほど）で 10ms ほど跳ぶこともあります。OBS などで受けているときは、OBS を開いたままで測ると本番に近くなりますが、それでも OBS が受け取る遅れとは数ミリ秒ずれることがあります。合わないと感じたら、測り直すか、遅らせ量を手で詰めてください。

出力先を3つ使う同時再生は、作者の手元の有線・USB の機器と仮想オーディオケーブルで確かめています。Bluetooth の機器は確かめていません。

年間まとめは、3.6.0 から再生を記録しています。3.5.0 までの版に戻して使っている間に再生した分は、記録されません（その版は記録の仕組みを知らないため。記録そのものは消えず、3.6.0 以降に戻すと続きから貯まります）。

手で選んだ色は、Dark と Light で別々には持てません。テーマを切り替えると、同じ色がもう片方のテーマにも当たります。また、手で選んだ色をスキンの zip に書き出すことはできません（設定のバックアップの zip には入ります）。

3.7.0 の新しい2つの色（ボタンの枠・お気に入りの星）を書いたスキンを 3.6.0 までの版で取り込むと、その2つは知らない名前として飛ばされます（ほかの色は使えます）。

Dark テーマで明るい背景画像を使い、曲一覧の行を選ぶと、行の中の灰色の文字（アーティスト名など）が少し読みにくいことがあります（3.6.0 と同じ。設定の「背景の暗さ」か「UI の不透明度」を上げると読みやすくなります）。

古い文字コードの読み直しは、すべての名前を正しく直せるわけではありません。

- 日本語の Shift_JIS が中心です。日本語の EUC-JP と中国語（GBK・Big5）の化けは、曲名がファイル名と同じときだけ直ります
- 直らない名前があります。多いのは、かなが無く、漢字と英字が空白なしで並ぶ名前です（「愛Love」「夏Remix」「MV集」など。漢字のすぐ後ろに英字が続く形は、ほとんど直りません）。「奏」「知」のような一部の漢字1文字だけの名前も直りません
- まれに、外国語の名前を漢字の列に変えてしまうことがあります（「‚Über‘」、引用符で囲んだ短い語の後ろに語が続く「“Bílá” Remix」、ダッシュやアポストロフィで空白なしにつないだ「Čaj–Řád」など）
- 一度直らなかった名前は、曲ファイルが変わらない限り、あとから自動では直りません。設定の「ライブラリ」の「古い文字コードのタグを読み直す…」で見直せます（直し方を良くした版で効きます）
- 読み直しでは、外国語の名前が漢字の列に変わってしまったものは元に戻りません
- 直らなかった名前や、変わってしまった名前に気づいたら、曲の右クリックの「タグを編集…」で正しい名前に直して保存してください

## 動作環境・通信

- Windows 10 / 11（x64）と WebView2 ランタイム（Windows 11 には標準で入っています。Windows 10 で起動しないときは、Microsoft の配布ページから WebView2 ランタイムを入れてください）
- インターネット接続は、「歌詞をネットから取る」をオンにしてボタンを押したときだけ使います（送り先は lrclib.net だけ）。オフの間は外へ通信しません。送るときの名札は `PL-Player/{{VERSION}} (https://github.com/rr2pp2/pl-player)` です（名前やメールアドレスは送りません）

使い方の全文・歌詞の受け渡しの取り決めは、公開ページ（https://github.com/rr2pp2/pl-player）の `README.md` にあります。
