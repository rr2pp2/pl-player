# PL Player {{VERSION}}

3.0.0 以降と同じアプリです（名前・データの場所・インストール先は変わりません）。前の版のライブラリ・設定・歌詞をそのまま使います。ふだんの使い方は変わりません。

## 3.5.0 で変えたこと

- **古い文字コードのタグを読み直すボタン**：設定の「ライブラリ」→「古い文字コード」に「古い文字コードのタグを読み直す…」を足しました。押すと確認のあと、ライブラリの全曲の曲名・アーティスト・アルバムなどを見直し、古い文字コード（Shift_JIS など）で化けたまま残っている名前を直します。あとの版で直し方を良くしたときに、取り込み済みの曲にも効かせるためのものです（この版の直し方は前の版と同じなので、今押しても、新しく直る名前はまずありません）
- 直すのはこのアプリのライブラリの表示だけで、曲ファイルには書き込みません。曲の右クリックの「タグを編集…」で手で直した名前は書き換えません（この版から、編集画面で変えた項目を覚えます。前の版までに編集画面で直した名前も、この版の直し方では変わりません）
- 裏で動くので、そのまま再生などを続けられます。進み具合が出て、「やめる」で止められます（それまでに直した曲はそのままです）。終わると、直した曲の数を知らせます。曲の取り込み・再走査の途中は始められません
- ウィンドウが狭いとき、設定の「歌詞を取ってくる」の進み具合の帯が見えなくなっていたのを直しました
- 曲一覧のコンパクト表示で、曲名とアーティストを別の列に分けました。見出しの「タイトル」「アーティスト」を押すと、それぞれで並べ替えます（コンパクトでない表示は今までどおりです）
- 設定の「表示」→「曲一覧の列」に「アーティスト」を足しました（はじめはオンです）。外すと、コンパクト表示ではアーティストの列を、ふつうの表示ではタイトルの下のアーティストを出しません。ウィンドウが狭くなっても、アーティストは自動では隠れません

## 中身

| ファイル | 使い方 |
|---|---|
| `PL Player 3_{{VERSION}}_x64-setup.exe` | インストーラー（今のユーザーにだけ入れる。管理者権限は要らない） |
| `PL Player 3（インストールせずに使う）.exe` | インストールせずにそのまま起動できる版。中身はインストーラーと同じ |

どちらを使っても、ライブラリ・設定は同じ場所（`%APPDATA%\jp.local.plplayer3\`）に置かれます。スタートメニューに出したいときはインストーラーを、置いた場所から起動するだけでよいときはインストールせずに使う版を選んでください。

## 「Windows によって PC が保護されました」と出たら

このアプリには、配った人を証明する署名（コード署名）を付けていません。そのため、初めて起動するときに Windows の青い画面（SmartScreen）が出ることがあります。

1. 画面の「詳細情報」を押す
2. 下に出る「実行」を押す

ダウンロードしたファイルが途中で壊れたり差し替えられたりしていないかは、公開ページの SHA256 の一覧（`PL-Player-{{VERSION}}.sha256.txt`）と照らして確かめられます。一覧に載っているのは公開ページに置いた名前（`PL-Player-{{VERSION}}.zip`・`PL-Player-{{VERSION}}-x64-setup.exe`・`PL-Player-{{VERSION}}-x64-portable.exe`）です。この zip から出した exe 2つは、名前は違いますが、それぞれ `-x64-setup.exe`・`-x64-portable.exe` と同じ中身なので、PowerShell の `Get-FileHash <ファイル>` の値が一覧のその行と同じになります（`Get-FileHash` は英字を大文字で、一覧は小文字で書いていますが、大文字小文字は問いません。英字の大小を無視して並びだけを見てください）。照らし方の全文は、公開ページの `README.md` の「入手」にあります。

## 気をつけること

- 「ごみ箱へ移す」は、USB メモリなどごみ箱の無い場所にある曲と、ごみ箱を使わない設定にしたドライブの曲は移しません（移すと完全に消えてしまうため）。ほかのアプリが使っている曲も移せません。移せなかった曲は、ファイルもライブラリもそのままです
- 「ごみ箱へ移す」で、ファイルはごみ箱へ移せたのにライブラリから外せなかった曲があると、そのことを知らせます。一覧に残るので、右クリックの「ライブラリから外す…」で外してください
- 「ごみ箱へ移す」で移した曲をごみ箱から戻しても、ライブラリには自動では戻りません。取り込み直してください（ライブラリに足したフォルダの中の曲なら、設定の「ライブラリ」の「再走査」でも入ります）。プレイリストとお気に入りの印は戻りません
- 設定のバックアップ（zip）を読み込むと、「ごみ箱」の列はオフに戻ります（右クリックのメニューの「ごみ箱へ移す…」はそのまま使えます）
- スキンで変わるのは、起動中のウィンドウ・タスクバー・タスクトレイのアイコンです。exe・スタートメニュー・デスクトップのショートカットのアイコンは変わりません
- 設定のバックアップ（zip）には、スキンそのものは入りません。別の PC で同じ見た目にするときは、設定の「着せ替え」でスキンを「書き出す…」し、その zip を取り込んでください
- 背景の暗さを低く（0〜30%）して暗い背景画像を使うときは、Light テーマの文字が読みにくくなることがあります。設定画面で「UI の不透明度」を上げてください
- HE-AAC でも、ファイルの頭に HE-AAC の印が無いもの（`.aac` のファイルなど）は、今までどおり高い音が欠けて聞こえることがあります
- Media Feature Pack を入れていない N エディションの Windows では、HE-AAC の m4a は今までどおり「非対応形式」になります（アプリは起動します）

## 既知の制限

古い文字コードの読み直しは、すべての名前を正しく直せるわけではありません。

- 日本語の Shift_JIS が中心です。日本語の EUC-JP と中国語（GBK・Big5）の化けは、曲名がファイル名と同じときだけ直ります
- 直らない名前があります。多いのは、かなが無く、漢字と英字が空白なしで並ぶ名前です（「愛Love」「夏Remix」「MV集」など。漢字のすぐ後ろに英字が続く形は、ほとんど直りません）。「奏」「知」のような一部の漢字1文字だけの名前も直りません
- まれに、外国語の名前を漢字の列に変えてしまうことがあります（「‚Über‘」、引用符で囲んだ短い語の後ろに語が続く「“Bílá” Remix」、ダッシュやアポストロフィで空白なしにつないだ「Čaj–Řád」など）
- 一度直らなかった名前は、曲ファイルが変わらない限り、あとから自動では直りません。設定の「ライブラリ」の「古い文字コードのタグを読み直す…」で見直せます（直し方を良くした版で効きます）
- 読み直しでは、外国語の名前が漢字の列に変わってしまったものは元に戻りません
- 直らなかった名前や、変わってしまった名前に気づいたら、曲の右クリックの「タグを編集…」で正しい名前に直して保存してください

## 動作環境・通信

- Windows 10 / 11（x64）と WebView2 ランタイム（Windows 11 には標準で入っています。Windows 10 で起動しないときは、Microsoft の配布ページから WebView2 ランタイムを入れてください）
- インターネット接続は、「歌詞をネットから取る」をオンにしてボタンを押したときだけ使います（送り先は lrclib.net だけ）。オフの間は外へ通信しません。送るときの名札は `PL-Player/{{VERSION}} (https://github.com/rr2pp2/pl-player)` です（名前やメールアドレスは送りません）

使い方の全文・歌詞の受け渡しの取り決めは、公開ページ（https://github.com/rr2pp2/pl-player）の `README.md` にあります。
